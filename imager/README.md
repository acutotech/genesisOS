# Genesis Imager

Writes Genesis OS to an SD card or USB drive with your user, password, Wi-Fi,
host name, time zone, keyboard and SSH settings, applied on the box's first
boot. See [the main README](../README.md#genesis-imager) for how to use it and
how it works.

* `genesis_imager.py`: the whole tool, Python 3.9+ standard library only
  (Tk for the window; the command line needs nothing else).
* `test_genesis_imager.py`: `python3 -m unittest discover -s imager -v`
  (synthetic disk images, no device or root rights needed).

The image side lives in `stage-custom/14-first-boot`: the setup-area
placeholder (`files/genesis-setup.txt`, generated by
`python3 imager/genesis_imager.py --write-placeholder FILE`; the tests fail if
the two disagree) and `genesis-firstboot`, which applies the settings.

Setup-area format (version 1): 16 blocks of 512 bytes in the boot partition,
each starting `#GENESIS-SETUP-AREA:v1:NN:16:`. Written, the 8192 bytes read as
`KEY=VALUE` lines, newline-padded:

```
GENESIS_SETUP=1
CREATED_BY=Genesis Imager 1.0.0
USER=nodoai
PASSWORD_HASH=$6$rounds=100000$<salt>$<hash>
HOSTNAME=nodobox
WIFI_COUNTRY=IN
WIFI_SSID_B64=<base64>
WIFI_PSK_B64=<base64>
WIFI_HIDDEN=0
TIMEZONE=Asia/Kolkata
KEYBOARD=us
KEYBOARD_VARIANT=
SSH=1
SSH_PASSWORD_AUTH=1
SSH_KEYS_B64=<base64, one key per line>
END=1
```

`END=1` must be present, or first boot applies nothing (a half-written card).
